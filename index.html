❓ Aide - OpenFarm

🔍 Recherche

Tapez le nom d'une plante dans la barre de recherche pour découvrir des informations détaillées.

  • ✨ Les suggestions apparaissent automatiquement
  • 🎯 Cliquez sur un tag populaire pour une recherche rapide
  • 📚 Les résultats proviennent de Wikipedia

⌨️ Raccourcis Clavier

  • Ctrl + K : Focus sur la recherche
  • Ctrl + D : Basculer le thème
  • Ctrl + H : Afficher l'aide
  • Escape : Fermer / Revenir en arrière
  • ↑ ↓ : Naviguer dans les suggestions
  • Enter : Sélectionner

❤️ Favoris

Ajoutez vos plantes préférées à vos favoris pour y accéder rapidement.

  • 🖱️ Cliquez sur le bouton cœur dans un article
  • 📋 Consultez tous vos favoris via le bouton "❤️" dans la barre de navigation
  • 💾 Vos favoris sont sauvegardés localement

🎨 Fonctionnalités

  • 🌙 Mode sombre/clair
  • 🔊 Lecture audio des articles
  • 🖨️ Impression des articles
  • 📊 Barre de progression de lecture
  • 🔗 Navigation entre articles

💡 Astuces

  • 🔄 Cliquez sur le logo pour revenir à l'accueil
  • 🌐 Tous les liens internes ouvrent dans l'application
  • 📱 L'interface s'adapte à tous les écrans
